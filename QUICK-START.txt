MAYKOVAL - QUICK START

WHAT'S INSIDE
  index.html        the storefront (all pages, cart, search, styling)
  api/shopify.js    secure server function that talks to Shopify
  vercel.json       hosting settings
  .env.example      template for your two secret settings
  README.md         full Shopify setup guide
No images or npm dependencies are needed: every product image comes
from your Shopify store, and the project uses no extra packages.

DEPLOY (about 15 minutes, free)
1. Shopify Admin > Settings > Apps and sales channels > Develop apps >
   create an app > enable the Storefront API scopes listed in README.md >
   install it > copy the "Storefront API access token".
2. Create a free GitHub account and a new repository. Upload the
   CONTENTS of this folder (keep the "api" folder).
3. Go to vercel.com, sign in with GitHub, click Add New > Project and
   import the repository. Do not change build settings.
4. Before clicking Deploy, open Environment Variables and add:
     SHOPIFY_STORE_DOMAIN       = your-store.myshopify.com
     SHOPIFY_STOREFRONT_TOKEN   = (your token)
5. Click Deploy. Your site goes live at a link like maykoval.vercel.app.
   Add your own domain under Settings > Domains.

RUN ON YOUR COMPUTER (optional)
1. Install Node.js (nodejs.org).
2. Copy .env.example to .env and fill in the two values.
3. In this folder run:  npx vercel dev
4. Open http://localhost:3000

AFTER LAUNCH
- Add/edit/delete products and collections in Shopify Admin; the site updates by itself.
- Make sure products are published to the Online Store sales channel.
- Fill in social links, support email and reviews in the CFG block at the top of the script in index.html.
